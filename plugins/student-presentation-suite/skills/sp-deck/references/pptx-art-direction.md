# Optional Art Direction

主会话依据内容与素材选择视觉语言。已有品牌或模板时保留用户指定的字体、颜色、logo 和版式约束。

Art Direction 文件可选，用于复用已有设计配置；不要求先填满风格字段、生成 wireframe 或校准报告。配色和 gallery 是参考，不是必须模仿的处理。

先决定每页要解释的关系，选择真实图片、可编辑图表或结构图，再安排文字。用少量一致的设计选择保持连贯，不靠重复边框、装饰条制造重点。重点来自语义层级：关键数字与关键词用加粗、重点色或适度放大（同一文本对象内多 run 实现行内强调），次要信息收缩，不靠机械放大一切。

字号由作者决定并按实际渲染调整，没有统一地板或比例；参考值：课堂投影正文 14–18pt、注释 10–12pt，每页主要文字层级控制在四档左右（大标题/板块标题/正文/页脚注释），同一角色内字体保持一致，标题与正文可有各自配对。body/list 行距保持 1.3 倍下限、多自然段默认段末间距；其他角色用真实字体度量、不默认加段距。告警均按角色收窄：字号过小 `text_size_review`、主要档位过多 `text_size_tiers`、同角色混字体 `font_family_mix`。生产方式见 [main-session-production.md](main-session-production.md)。
