# Ocean Tech（海洋科技）

- **Style character:** Cool, technical and current; engineered rather than decorative. Hierarchy comes from a 40pt cover / 32pt title / 26pt statement / 22pt body / 11pt caption scale, and the accent only marks the emphasised line, the recommended option, the key number and the conclusion.
- **Palette:** canvas `F4F9FC`; surface `FFFFFF`; primary text `132238`; secondary text `52677A`; primary accent `065A82`; secondary accent `1C7293`.
- **Background reference:** cover uses the dark field `0D1A2D` with `C0D2DD` titles and `1E9AD4` accents; content uses the light canvas `F4F9FC` with `FFFFFF` surfaces only where grouping is meaningful, plus an evidence-rail accent rule; section reuses the dark field with a single accent cue; closing returns to the dark field with a `30657E` hairline source rail. The dark scheme `0D1A2D` / `192941` is the deliberate counterpart of the light `F4F9FC` / `FFFFFF`, so cover and body pages stay one colour family.
- **SVG reference:** `ocean-circuit` — Optional circuit, node, or signal-path motif on technical overview pages.
