# Data Driven（数据驱动）

- **Style character:** Analytical and quantitative; the chart and the number carry the argument, not decoration. Hierarchy comes from a 40pt cover / 32pt title / 26pt statement / 22pt body / 11pt caption scale, and the accent only marks the emphasised line, the recommended option, the key number and the conclusion.
- **Palette:** canvas `F8FAFC`; surface `FFFFFF`; primary text `111827`; secondary text `4B5563`; primary accent `2563EB`; secondary accent `16A34A`.
- **Background reference:** cover uses the dark field `0F1A25` with `C6D6E4` titles and `4290F0` accents; content uses the light canvas `F8FAFC` with `FFFFFF` surfaces only where grouping is meaningful, plus an evidence-rail accent rule; section reuses the dark field with a single accent cue; closing returns to the dark field with a `2E7D4F` hairline source rail. The dark scheme `0F1A25` / `1B2A38` is the deliberate counterpart of the light `F8FAFC` / `FFFFFF`, so cover and body pages stay one colour family.
- **SVG reference:** `data-axis` — Optional axis, bracket, or data-point motif; never substitute it for an actual chart.
