# Creative Student（创意学生）

- **Style character:** Warm and human; a studio-notebook feel with a single warm accent. Hierarchy comes from a 40pt cover / 32pt title / 26pt statement / 22pt body / 11pt caption scale, and the accent only marks the emphasised line, the recommended option, the key number and the conclusion.
- **Palette:** canvas `F7F4EF`; surface `FFFFFF`; primary text `1F2937`; secondary text `596273`; primary accent `C4510B`; secondary accent `0EA5E9`.
- **Background reference:** cover uses the dark field `221A14` with `EADCC8` titles and `E8761F` accents; content uses the light canvas `F7F4EF` with `FFFFFF` surfaces only where grouping is meaningful, plus an evidence-rail accent rule; section reuses the dark field with a single accent cue; closing returns to the dark field with a `8A5A34` hairline source rail. The dark scheme `221A14` / `33281E` is the deliberate counterpart of the light `F7F4EF` / `FFFFFF`, so cover and body pages stay one colour family.
- **SVG reference:** `studio-tape` — Optional tape or studio-note motif; use only when it supports process or iteration.
