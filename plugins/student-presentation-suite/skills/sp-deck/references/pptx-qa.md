# PPTX inspection

`ppt_pipeline.py run` 批量构建并检查当前 PPTX 的结构、精确项和数字，输出渲染预览及实际文本。检查报告由工具生成，不要求视觉评分、critic 或回执。

主会话查看总览和当前单页，检查重点是否清楚、信息关系能否看懂、字体是否实际可读、中文断行是否自然、素材关键部分是否完整、来源和讲稿是否对应事实。需要时查看局部原尺寸图；不要把总览图当成小字验收。

同一会话直接修改页面，再调用 `run`。事实和语义的自检应基于实际文本和讲稿；没有独立评审保证。完成后 `complete` 只导出已确认类型，编辑另外写 change summary。只读诊断走 `sp-review`，不得修改原件。
