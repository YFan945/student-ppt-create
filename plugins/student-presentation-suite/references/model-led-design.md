# Main-session design

主会话阅读材料、设计页面、实现并查看渲染后修复。内容、字号、坐标、配色、图片和版式由作者根据任务决定。用户指定的模板、品牌、精确事实和保留项继续有效。

新任务脚手架只携带配色、字体族、用户提供的 typography 和事实输入，不注入旧字号上下限、标题/页脚分区、列数、间距、线型、面板、母题、背景节奏或布局推荐。页面函数获得完整画布；运行时登记实际元素、写备注和检查产物，不自动绘制背景或切换设计模式。design_freedom 字段继续可读，不限制页面函数和绘图 API。

保留有用的解释、例子、证据和支撑关系；讲稿服务于演讲，不替代听众需要看到的内容。避免把材料压成大字短句、空白卡片和统一结论带。材料不足时补查提供的材料或明确缺口，不编造事实来填满页面。

## 充实正文与重点讲解

正文供观看、选择性讲解和课后阅读，短演讲不自动要求稀疏页面。保留必要细节，用加粗、适度放大、重点色、位置和分组突出讲述路径；备注简短地讲重点、关键解释和转场，不复述全部正文。封面、转场、结论和证据页可有不同密度，密度以材料和实际可读性判断。

## 视觉关系

- 同级标题、同类证据与标注保持一致；主题、分组、证据、解释和来源跨级可辨认。颜色承担强调或分类角色，不靠颜色数量制造层级。
- 先确定阅读顺序与信息关系，再分配区域。相关元素对齐、标签靠近对象、连接线归属清楚；组内关系比组间更紧密。
- 作者选择标题处理、图片处理、标注、字体配对和间距习惯，并保持套件一致性；不同内容可用不同构图，不强制统一母题、配色面积或背景节奏。
- 积极组合图片、表格、图表与结构图。有意义的面板、边框、导航和图标可帮助组织；避免无用途的碎片标签、空容器和全套机械重复。
- 拥挤时先去重复、优化措辞与分组，再调整区域/素材，页数允许时拆页，最后调整字号；不通过删掉必要证据或只缩字解决布局。
- 实际检查文本、图片叠字、图例与分类色的对比；尊重中文/西文字体和模板，检查字体替换、语义断行及加粗后的空间。

封面与模板的操作见 `../skills/sp-deck/references/cover-and-template.md`；图像获取与允许的设计占位见 `image-strategy.md`。这些原则指导模型选择，不给脚手架注入固定坐标、字号或版式。

Slide Spec 2.1 冻结 semantic_requirements.must_convey 与 must_show_exact；展示文案可重写，实际文案记录为 presentation_copy。旧 Spec 的明确文案契约保持有效；新任务不自动添加字数上限。

按实际需求和参考件检查所有最终渲染页，修复后重新渲染。检查真实可读性、裁切、意外遮挡、图文关系及信息完整性；再用符合课堂投影或目标观看条件的缩放检查重点、表格和图例。技术报告的 ok 仅对应技术检查，不证明审美或完整语义。源码接口与命令见 ../skills/sp-deck/references/main-session-production.md。
